# Custom skills (optional)

In OpenClaw, **skills** are extra capability bundles: each skill is a folder that includes a **`SKILL.md`** describing tools or workflows the agent can follow (automation, APIs, internal procedures). They are optional—WhatsApp/channel setup from the blog does not require custom skills.

If you use skills, configure OpenClaw to load this directory (see OpenClaw configuration for `skills` / custom paths).

Documentation: https://docs.openclaw.ai/
